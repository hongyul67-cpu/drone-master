# 드론 제작 마스터

특성화고 항공드론과 「드론 제작」 교과용 학습 도구. 정적 HTML만으로 동작하며 GitHub Pages로 배포한다.

**배포 주소** — https://hongyul67-cpu.github.io/drone-master/

## 구성

| 파일 | 내용 | 근거 |
|---|---|---|
| `index.html` | 허브. 카드 링크에 `?rc=`를 자동으로 물려 준다 | — |
| `build-sim-pixhawk.html` | 만들기 게임 7단계: 부품 도감 → 프레임·모터 조립 → 픽스호크 결선 → 프로펠러 → 조종기 세팅 → 미션 플래너 보정 → 가상 시험비행 | 교과서 Ⅳ영역 (p120~166) |
| `build-sim-arduino.html` | 만들기 게임 6단계: 부품 도감 → FC 기판 핀 결선 → 3D 출력 설정 → 모터·ESC 조립 → MultiWii 세팅 → ESC 보정·비행모드·안전점검 | 교과서 Ⅲ영역 (p84~119) |
| `report.html` | 실습 보고서. 게임 기록 자동 유입 · 자기평가 루브릭 · 서술형 4문항 · 사진 첨부 · A4 인쇄/PDF | 교과서 「실습 점검」 루브릭 |
| `03-drone-structure.html` | 이론 3차시 · 드론의 구성 (배우기 → 조립게임 → 센서게임 → 학습지) | 3차시 학습지 |

## 도구 사이의 연결

- 게임을 끝내면 결과가 `localStorage`에 저장된다 (`drone_build_pixhawk`, `drone_build_arduino`).
- 보고서가 그 값을 읽어 단계별 실수 횟수까지 자동으로 채운다. 게임 없이 보고서만 써도 된다.
- 게임 결과 화면의 「보고서 쓰러 가기」는 `?rc=`를 그대로 넘긴다.

## 결과 수집

`https://hongyul67-cpu.github.io/links/collector.js` 위젯을 쓴다.
교사가 `?rc=<본인 Apps Script exec 주소>`를 붙인 링크로 나눠 줄 때만 제출 버튼이 나타난다.
보고서는 서술형 4문항 본문을 `wrong` 필드에 담아 보내므로 **시트에서 학생 글을 바로 읽을 수 있다** (사진은 전송하지 않음 — 인쇄본으로 제출).

## 알아 둘 것

- 교과서 89쪽 결선표에는 `SDA=A5, SCL=A4`로 적혀 있으나 88쪽 설명과 아두이노 나노 실제 핀 배치는 `A4=SDA, A5=SCL`이다. 게임은 실제 배치를 정답으로 하고 화면에 경고를 띄운다.
- 모터 번호 규칙이 FC마다 다르다. 픽스호크(ArduPilot) 쿼드X는 1=앞·오른(CCW), 2=뒤·왼(CCW), 3=앞·왼(CW), 4=뒤·오른(CW). MultiWii 방식은 1·3=CW, 2·4=CCW. 두 게임이 서로 다른 것이 맞으며, 아두이노 게임에서 이 차이를 경고로 설명한다.
- 이론 1·2·4·5·6차시는 아직 없다. `03-drone-structure.html`과 같은 틀(배우기 → 게임 → 학습지)로 추가하면 된다.
